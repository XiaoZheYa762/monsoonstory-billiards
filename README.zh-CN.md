# 季风物语：桌球

[English](README.md)

[版本下载](https://github.com/XiaoZheYa762/monsoonstory-billiards/releases) · [源码仓库](https://github.com/XiaoZheYa762/monsoonstory-billiards) · [问题反馈与授权申请](https://github.com/XiaoZheYa762/monsoonstory-billiards/issues)

在 Minecraft 世界里游玩休闲八球、九球和单人练习，支持双人对局、旁观、三色球桌与普通球杆、击点旋转、瞄准预测、连续观球镜头及球房家具。


## 安装

客户端和服务器均须安装对应游戏版本、加载器的同一版本模组。

| 游戏版本与加载器 | Java | 必需依赖 |
|---|---|---|
| Fabric 1.20.1 | 17 或更新 | Fabric Loader 0.16.9 或更新、Fabric API |
| Forge 1.20.1 | 17 | Forge 47.4.28 |
| NeoForge 1.21.1 | 21 | NeoForge 21.1.264 或更新的同游戏版本构建 |
| NeoForge 26.1 | 25 | NeoForge 26.1.0.19-beta |

Better Combat 为可选兼容。未安装时，普通球杆仍支持原版左键攻击和右键蓄力前戳。无需安装其他季风物语模组。

## 开始打球

在“季风物语：桌球”创造分类找到物品，或通过生存配方制作。球桌需要平整、受支撑且空旷的 **10×6** 区域。放置后右键球桌，选择练习或创建对局；第二名玩家加入并准备后开始。

持杆右键球桌进入瞄准，先松开进入时的右键，再按住蓄力，松开击球。`G` 切换瞄准线，`Alt` 调整击点，`R` 回中，`Shift` 精细瞄准，`O` 打开设置，`V` 切换全景机位，`Esc` 取消瞄准。按键可在原版设置中修改。

八球使用界面说明的休闲家规，黑八需要报袋；九球要求先接触场上号码最小的目标球。当前不包含斯诺克。所有附近玩家均可重置球桌；拆桌由放置者和 OP 管理。

| 制作物品 | 每件材料 |
|---|---|
| 三色球桌 | 对应颜色地毯×3、木板×4、铁锭×1 |
| 三色普通球杆 | 木棍×2、铁粒×1、对应颜色地毯×1 |
| 球杆架 | 木棍×4、木板×3 |
| 落地计分板 | 木板×6、红色染料×1、蓝色染料×1 |
| 三色台球灯 | 木板×3、铁锭×2、对应颜色地毯×1、灯笼×3 |

深蓝款使用蓝色地毯，摆放方式可查看配方书。普通杆最高力度 100%，耐久 128；打球不消耗耐久，成功战斗命中消耗耐久。球杆架保存六槽物品及其数据。计分板右键对应一侧加分，潜行右键清零。台球灯需要顶部支撑。纪念球保留对局获胜奖励机制，临时白球仅作为服务端发放的摆球工具。

## 管理员上传音乐

仅权限等级 2 或更高的 OP 可在球桌音乐界面选择本地 **OGG Vorbis** 文件并上传、选曲和操作播放。普通玩家靠近后收听，各自调整音量，默认 25%。不内置背景歌曲。

8 格内进入、10 格外退出并淡出；多桌同时播放时只收听其中一张附近球桌。下载完成后从共同播放进度开始，静音时停止音乐下载。歌曲选择会保存，服务器重启后暂停，等待管理员继续。

默认单曲限制 20 MiB、10 分钟，曲库总量 1 GiB，总传输限速 1 MiB/s，服主可调整。音乐保存在世界目录下的 `monsoonstory_billiards/music`，客户端下载为本地缓存。
